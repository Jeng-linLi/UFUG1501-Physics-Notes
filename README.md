## 涵蓋重點

**Week 5**
- 位能與系統組態、ΔU = −W
- 保守力 vs 非保守力、路徑獨立性
- 重力位能 U = mgz、彈力位能 U = ½kx²
- 力學能守恆、位能曲線（F = −dU/dx、轉折點、平衡點）
- 外力作功（有／無摩擦）、能量守恆、功率
- 靜力平衡（ΣF = 0、Στ = 0）、重心 vs 質心
- 應力與應變、楊氏／剪／體積模量

**Week 7**
- 牛頓萬有引力定律、球殼定理、疊加原理
- 地表重力、自轉效應、地球內部的簡諧運動
- 重力位能 U = −GMm/r、逃逸速度
- 克卜勒三定律、衛星軌道與能量
- 愛因斯坦重力觀（等效原理、時空彎曲、重力透鏡）
- 密度、壓力（絕對／錶壓）、靜止流體
- 帕斯卡原理與液壓槓桿、阿基米德原理
- 理想流體、連續方程、伯努利方程
